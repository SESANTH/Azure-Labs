# Day 6 – Azure Virtual Networks

## Objective

Learn Azure Virtual Networking concepts including VNets, Subnets, Private IPs, Public IPs, and Azure DNS.

## Concepts Learned

- Virtual Network
- Address Space
- Subnets
- Private IP
- Public IP
- Azure DNS

## Hands-on Tasks

- Created a Virtual Network
- Configured Address Space
- Created Subnet-A
- Created Subnet-B
- Explored Azure DNS settings

## Key Learnings

- A VNet provides a private network for Azure resources.
- Subnets divide a VNet into smaller logical networks.
- Private IPs enable internal communication.
- Public IPs allow Internet access.
- Azure DNS provides internal name resolution.

### Why use Subnets?

Subnets logically separate resources within a Virtual Network, improving security, organization, scalability, and allowing different security policies for different workloads.
