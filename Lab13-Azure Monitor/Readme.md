## Interview Questions

Q1. What is Azure Monitor?

Azure Monitor is a centralized monitoring service that collects, analyzes, and visualizes metrics, logs, and alerts from Azure resources.

Q2. Metrics vs Logs

| Metrics                  | Logs                     |
| ------------------------ | ------------------------ |
| Numeric performance data | Detailed event records   |
| Time-series              | Searchable records       |
| Used for dashboards      | Used for troubleshooting |

Q3. What is Activity Log?

The Activity Log records Azure management operations such as resource creation, deletion, configuration changes, and RBAC assignments.

Q4. What are Alerts?

Alerts automatically notify administrators when defined conditions are met, such as high CPU utilization or resource health issues.

Q5. What is an Action Group?

An Action Group defines the notification or automation that occurs when an alert is triggered, such as sending an email or invoking a webhook.

### Metrics vs Logs

Metrics are numerical performance measurements collected over time.
Logs contain detailed records of events for troubleshooting and auditing.
