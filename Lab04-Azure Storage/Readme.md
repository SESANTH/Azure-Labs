# Day 4 – Azure Storage

## Objective
Learn Azure Storage services including Blob Storage, Azure Files, Queue Storage, Table Storage, Access Tiers, and SAS Tokens.

## Concepts Learned
- Storage Account
- Blob Storage
- Azure Files
- Queue Storage
- Table Storage
- Hot, Cool, Archive Tiers
- Shared Access Signature (SAS)

## Hands-on Tasks
- Created a Storage Account
- Created a Blob Container
- Uploaded PDF, Image, and ZIP files
- Generated a SAS Token
- Created an Azure File Share
- Explored Queue Storage
- Explored Table Storage

## Key Learnings
- Storage Accounts host multiple storage services.
- Blob Storage is optimized for unstructured files.
- Azure Files provides SMB-based shared storage.
- Queue Storage enables asynchronous processing.
- Table Storage is a NoSQL key-value store.
- SAS Tokens provide temporary, secure access without exposing account keys.

### Blob vs File Share
Blob Storage stores unstructured objects accessed through HTTP/HTTPS APIs.
Azure Files provides SMB/NFS file shares that multiple machines can mount and use like a traditional network drive.
