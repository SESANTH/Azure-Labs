# Day 2 – Microsoft Entra ID

## Objective
Learn how Azure manages identities using Microsoft Entra ID.

## Concepts Learned
- Microsoft Entra ID
- Tenant
- Users
- Groups
- Administrative Units
- Guest Users

## Hands-on Tasks
- Explored Microsoft Entra ID
- Created five users (Admin, Developer, Tester, HR, Finance)
- Created Security Groups
- Added users to groups
- Explored Administrative Units
- Walked through inviting a Guest User

## Key Learnings
- A Tenant stores identities and access policies.
- Users represent identities that can sign in.
- Groups simplify permission management.
- Guest users enable secure collaboration with external users.
- Administrative Units help delegate administration in large organizations.

## Interview Questions

### User vs Group
A User is an individual identity that signs in to Azure. A Group is a collection of users used to manage permissions more efficiently.

### Tenant vs Subscription
A Tenant manages identities, authentication, and authorization. A Subscription is used to manage Azure resources and billing.
